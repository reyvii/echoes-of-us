# echoes-of-us
Наш инструмент для анализа и красивой визуализации истории личных переписок. Превратите тысячи сообщений в интерактивную историю ваших взаимоотношений.

**Echoes of Us** — это визуализатор истории переписок, который превращает сухие логи чатов из мессенджера (Telegram) в наглядную, эстетичную и интерактивную инфографику. 

Проект создан для того, чтобы взглянуть на историю общения со стороны: вспомнить, с чего всё начиналось, увидеть динамику диалога за месяцы или годы и найти самые тёплые моменты.

## 🌟 Основные возможности

* **Хронология активности:** графики интенсивности общения по дням, месяцам и времени суток.
* **Анализ слов и эмодзи:** облако самых частых фраз, любимые стикеры и главные локальные мемы.
* **Статистика диалога:** кто пишет первым, средняя длина сообщений, скорость ответа и общее количество слов.
* **Карта воспоминаний:** поиск самых длинных переписок за день и ключевых дат.
* **Приватность прежде всего:** вся обработка данных происходит локально на вашем устройстве — ваши личные сообщения никуда не загружаются.

## 🔒 Безопасность и конфиденциальность

Проект работает полностью на стороне клиента (или локально). Ваши файлы экспорта переписок не отправляются на сторонние серверы и не сохраняются в облаке.
